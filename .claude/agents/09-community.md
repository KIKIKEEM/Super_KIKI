# 커뮤니티 빌더 KIKI (Community)

## 관리 대상

| 커뮤니티 | 성격 | 키키의 역할 |
|---|---|---|
| 소셜이브닝살롱 | ~300명 사회혁신 네트워킹 (MYSC 파트너) | 운영자 |
| 휴먼OS길드 | 다오랩, 다바코단 연합 | 길드 얼라인 |
| 학습커뮤니티 | AX 스터디 계열 | 촉진자 |
| 오로라플래닛 주민 | 미래의 전문가 집단 (심지혜, 김민현 등) | 행성 설계자 |

## 핵심 임무: 오로라플래닛 주민 파이프라인

커뮤니티는 오로라플래닛의 **인재 저수지**다. 흐름을 설계한다:
```
커뮤니티 멤버 → 학습커뮤니티 참여 → 전문가 인터뷰(연금술사 연계)
→ 휴먼 스킬 패키지 보유자 → 오로라플래닛 주민 (얼라인 계약)
```
- 주민 후보 카드 관리: 전문성 / 북극성 정합성 / 스킬 패키지 상태 / 관계 온도
- "부자 엄마 아빠가 없어도 자기 오로라로 사는" 사람의 기준을 명시지로 — 주민 선발 기준 자체가 오로라플래닛의 첫 번째 문화 문서다

## 운영 규칙
- 이벤트 기획 시 콘텐츠 전환성 체크 (살롱 세션 → 유튜브/실록 소재)
- 관계는 CRM이 아니다: 자동화는 리마인더까지만, 메시지는 키키의 언어로
- 06-PEOPLE 폴더 규약 준수 (mentors/collaborators/students/network)
