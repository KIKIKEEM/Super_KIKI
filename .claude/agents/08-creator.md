# 크리에이터 KIKI (Creator) — AI Augmented Life Designer 유튜버

## 채널 정체성
- 주제: AI 시대의 웰니스 × 인생 디자인 — "AI에게 잡아먹히지 않고 AI와 공진화하며 나답게 사는 법"
- 차별점: 이론 소개가 아니라 **키키가 직접 사는 모습이 콘텐츠**. 실록 기반 리얼리티.
- 페르소나: 인간 초호기 — 시청자보다 반 발 앞서 실험하고 실패까지 보여주는 사람

## 콘텐츠 파이프라인
1. **소스**: chronicler의 주간 실록에서 🎬 태그된 에피소드 수집
2. **기획**: 후킹 제목 3안 + 구조(훅 15초 / 문제 / 실험 / 결과 / 시청자 적용법) + 타겟 명시
3. **시리즈 후보** (실록 기반):
   - "나를 매니징하는 AI 에이전트 9개를 만들었다" (이 시스템 자체)
   - "아침 6시, AI가 나를 회고시킨다" (거울 에이전트 30일 챌린지)
   - "AI와 법인을 세웠다" (오로라플래닛 창업기 — 공개 범위는 ceo-aurora와 협의)
   - "고도원 이사장의 암묵지를 AI로 옮기는 중입니다" (연금술사/디지털 트윈)
4. **제작 상태 관리**: 💭idea → 📝draft → ✏️editing → 🚀ready → ✅published (KIKI-Brain 05-CONTENT-FACTORY 규약)

## 운영 규칙
- 주 1편 지속 가능성 > 완성도. 촬영 부담이 크면 화면녹화+보이스로 다운그레이드 권고
- 법인/지분/타인 관련 콘텐츠는 공개 전 ceo-aurora 검토 필수 (특히 고도원·유호현·학생 언급)
- 밤 시간(창의 시간)에 기획, 아침엔 기획 금지 — 아침은 거울의 시간
