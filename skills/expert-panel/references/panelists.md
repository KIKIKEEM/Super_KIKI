# 패널리스트 로스터 — 4단계 캐스팅 보조

`SKILL.md` 4단계에서 **키키 결정 안건**의 고정 슬롯(이해관계자 대리 1인 + 레드팀 1인)을 채울 때 쓴다. 나머지 4석은 원본 기준대로 근거 지형(2단계)에서 나온 실명 연구자·실천가로 채운다 — 이 문서는 그 자리를 대체하지 않는다.

캐스팅은 "직함"이 아니라 **렌즈**를 고르는 일이다. 같은 안건에 같은 결론을 낼 사람 둘을 앉히면 패널이 아니라 합창이다. **서로 다른 방향으로 틀릴 사람**을 고른다.

각 항목: 렌즈 / 첫 질문 / 이 렌즈가 자주 놓치는 것(= 함께 앉힐 보완 패널리스트).

---

## A. 내부 패널 — Super KIKI 에이전트 (CLAUDE.md 6장)

키키의 자원·리듬·법인 맥락을 아는 렌즈가 필요할 때 추가로 캐스팅한다. 이들은 근거 태그를 면제받지 않는다 — 주장에는 똑같이 `[Expert]` 이상의 태그와 한계 고지가 붙는다.

| 패널리스트 | 렌즈 | 첫 질문 | 놓치는 것 |
|---|---|---|---|
| **거울 (mirror)** | 에너지·정합성. 헌법이 보장한 쓴소리 권한 보유 | "이걸 하면 아침 6시와 밤 창의 시간 중 무엇이 깨지는가?" | 기회의 상방(upside) — 낙관 렌즈와 함께 앉힐 것 |
| **사관 (chronicler)** | 시간 축. 6개월 뒤 이 기록이 어떻게 읽히는가 | "이 결정은 키키실록의 어느 장(章)이 되는가?" | 단기 현금·마감 압력 |
| **CEO-aurora** | 법인·지분·PMF | "이게 오로라플래닛 지분 35%의 전제조건과 충돌하는가?" | 개인 서사·논문의 리듬 |
| **학자 (scholar)** | 논증 구조, 선행연구, 반증 가능성 | "이 주장의 반증 조건은 무엇인가?" | 속도, 시장 타이밍 |
| **교육자 (educator)** | 학습자 경험, 커리큘럼화 가능성 | "이걸 3시간 모듈로 쪼갤 수 있는가?" | 수익성, 확장성 |
| **크리에이터 (creator)** | 후킹, 패키징, 채널 성장 | "이 경험의 썸네일과 제목은 무엇인가?" | 깊이, 장기 신뢰 |
| **커뮤니티 (community)** | 주민 경험, 신뢰 자본 | "이 결정으로 신뢰를 잃는 사람이 있는가?" | 단호한 손절 |
| **연금술사 (alchemist)** | 암묵지의 자산화 | "이 일을 두 번째 할 때 남는 스킬은 무엇인가?" | 첫 실행의 비용 |

## B. 외부 전문가 아키타입

2단계 근거 지형에서 실명 연구자를 못 찾았거나(니치 주제), 실명 오귀속 위험이 커서 역할 아키타입 패널을 택한 경우(4단계 민감 주제 가드) 이 목록에서 뽑는다.

| 패널리스트 | 렌즈 | 첫 질문 | 놓치는 것 |
|---|---|---|---|
| **스타트업 전문 변호사** | 계약 문언, 최악의 이별 시나리오 | "관계가 깨졌을 때 이 문서는 누구 편인가?" | 관계의 신뢰 자본, 속도 |
| **CFO / 재무** | 런웨이, 고정비, 현금 흐름 타이밍 | "이 결정의 첫 12개월 현금 곡선은?" | 비재무적 자산(신뢰·서사) |
| **VC 투자심사역** | 규모 확장성, 창업자-시장 적합성 | "왜 지금, 왜 이 팀인가?" | 작지만 지속 가능한 삶 |
| **논문 심사위원** | 방법론 타당성, 기여도 | "기존 연구와 무엇이 다른가? 데이터는 방어되는가?" | 실무적 임팩트 |
| **교육정책 관료** | 제도 정합성, 공공성, 확산 가능성 | "이걸 학교 1만 개에 적용하면 어디서 부러지는가?" | 개인 혁신의 속도 |
| **유튜브 그로스 전략가** | CTR·리텐션·발행 리듬 | "이 활동이 주 1편 발행을 지키는가 깨는가?" | 콘텐츠의 진정성 피로도 |
| **브랜드 전략가** | 포지셔닝 일관성 | "이 결정이 '초호기' 서사를 흐리는가?" | 실험의 필요성 |
| **조직심리학자** | 권력 구조, 암묵적 기대, 번아웃 | "말해지지 않은 기대는 무엇인가?" | 숫자·계약 |
| **시간·에너지 코치** | 총량 불변, 회복 리듬 | "무엇을 죽이고 이걸 넣는가?" | 예외적 기회비용 |
| **운영 실무자 (오퍼레이터)** | 실행 디테일, 누가 실제로 하는가 | "이 계획의 3주차 화요일에 누가 무엇을 하는가?" | 비전 |
| **Implementation 과학자** | Core vs Peripheral, 적응 설계 | "효과를 만드는 최소 핵심은 무엇이고, 무엇은 바꿔도 되는가?" | 근거 자체의 강도 |

## C. 관점 대리 패널리스트 — 이해관계자 대리 슬롯 (주의)

실존 인물이나 미래의 자신을 대리하는 자리. **모델이지 그 사람이 아니다.**

> 산출물은 "그 사람이 이렇게 말할 것"이 아니라 **"그 사람에게 이걸 직접 물어야 한다"**이다.
> 발언 앞에 `(시뮬레이션)`을 병기하고, 확인이 필요한 항목은 6단계 "확인할 사실"로 반드시 넘긴다. 4단계 민감 주제 가드와 Hard Rules #7이 그대로 적용된다.

| 패널리스트 | 렌즈 | 취급 규칙 |
|---|---|---|
| **미래의 키키 (10년 후)** | 북극성 도달 시점에서의 역산. 주식회사 키키 정관상 34% 거부권 주주 | 감정 아닌 서사 정합성으로만 발언 |
| **공동창업자 관점** | 상대의 리스크와 기대 (예: 상근·투입량 전제조건) | 실제 발언 아님 명시 + 직접 질문으로 6단계에 남길 것 |
| **최대주주/이사회 의장 관점** | 자본과 명분의 보호 | 위와 동일 |
| **오로라플래닛 주민 (수혜자)** | "부자 엄마 아빠 없는 사람"에게 이 결정이 무엇을 바꾸는가 | 가장 자주 빠지는 자리 — 의심스러우면 넣어라 |
| **떠난 사람 / 거절당한 사람** | 이 결정의 비용을 치른 쪽 | 커뮤니티·채용·파트너십 안건에 필수 |

## D. 레드팀 — 필수 슬롯

4단계 선정 기준의 "비판적 관점 1인"과 겸한다.

| 변형 | 시작 전제 |
|---|---|
| **회의론자** | "이 결정은 이미 정해놓고 정당화를 찾는 중이다" |
| **2년 뒤 부검의** | "이건 실패했다. 이제 원인을 쓴다" (→ `protocols.md` 프리모템) |
| **경쟁자** | "나는 이 빈틈을 어떻게 이용하는가" |
| **감사(監査)** | "여기서 규정·약속·정관을 어기는 지점은 어디인가" |
| **Gottman 검사관** | "이 합의는 근거가 있어서 나온 것인가, 권위가 반복돼서 나온 것인가" (2단계 Gottman 경고와 연결) |

## 캐스팅 레시피 (안건 유형별 고정 슬롯 기본값)

아래는 **6인 중 고정 2석**의 기본값이다. 나머지 4석은 근거 지형에서 나온다.

| 안건 | 이해관계자 대리 | 레드팀 |
|---|---|---|
| 지분·계약·법인 구조 | 공동창업자 관점 | 2년 뒤 부검의 |
| 새 강의·컨설팅 수락 여부 | 미래의 키키 | 회의론자 |
| 논문 방향·챕터 설계 | 지도학생 / 심사위원 | Gottman 검사관 |
| 유튜브·콘텐츠 큰 베팅 | 주민(시청자) 대리 | 경쟁자 |
| 커뮤니티 정책·멤버십 | 떠난 사람 | 감사 |
| 제품 실험 PMF 판정 | 주민(첫 사용자) 대리 | 2년 뒤 부검의 |
| 개인 리듬·번아웃 | 미래의 키키 | 회의론자 |

레시피는 출발점일 뿐이다. 안건 고유의 사각지대가 보이면 갈아끼우고, **왜 이 사람을 뺐는지**를 한 줄로 남긴다.
